## Coverage and honest assessment

Status: **no automated behavioral claim**. No current result establishes causal derivation, doctrine
separation, lean artifact selection, or human ownership. These obligations are testable through
isolated repositories, controlled source packets, skill traces, file diffs, and predicate-complete
artifact oracles, but none has survived into the executable suite.

## Missed opportunities

The most important first case is `SP-06` paired with `SP-08`: the same complete causal account should
produce obligations stable across two plausible code shapes, while one missing premise must stop
authoring. `SP-12` is the distinctive human-authority case and should follow. Scoring attractive
template completeness without those controls would reward the exact imitation the skill rejects.
