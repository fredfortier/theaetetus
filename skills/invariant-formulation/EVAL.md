# Evaluation: `invariant-formulation`

## Skill obligations and how Codex can test them

[`SPEC.md`](SPEC.md) is the sole source of behavioral authority. The following rows translate each
obligation into a concrete Codex Promptfoo test and do not themselves govern runtime behavior.

| ID | Obligation | Promptfoo scenario and falsifier |
| --- | --- | --- |
| `IF-00` | Activate only when owned reasoning must become stable properties, not to discover intent or prescribe implementation. | Pair an owned causal account with a vague feature request and a coding request. Only the owned account may yield invariants; the others must stop or route without invented requirements or edits. |
| `IF-01` | Bind every invariant to an owned premise and governed subject. | Supply one owned premise and one unowned preference. Current must formulate only the owned subject relation and return the other as missing; a preference-preserving control fails. |
| `IF-02` | Ground premises that depend on factual or external support. | Make one premise depend on a repository fact and another on an external contract. Traces and labels must distinguish both supports; unsupported-premise mutation fails. |
| `IF-03` | State valid behavior positively and expose its illegal negation once. | Give a blacklist-style input. A structural oracle requires one positive property plus one negation and rejects copied prohibition lists. |
| `IF-04` | Name enforcement and verification boundaries. | Supply multiple components but one actual state owner. The output must identify that owner and an observation at its boundary; file-level proxy controls fail. |
| `IF-05` | Reject task-, symptom-, file-, and prose-shaped candidates. | Test one candidate of each weak shape against one valid invariant. Each negative must be rejected for its precise reason; aggregate rubric scores cannot compensate. |
| `IF-06` | Compress overlapping candidates without weakening meaning. | Provide three overlapping constraints whose conjunction has one stronger domain property. Current must return the minimal property and preserve every ruled-out illegal state. |
| `IF-07` | Return missing premises instead of inventing intent. | Omit failure semantics from a lifecycle request. Current must identify the exact missing owner decision and stop; a plausible-default mutation fails. |

## Coverage and honest assessment

Status: **no automated behavioral claim**. Source quarantine does not exercise invariant quality.
The obligations are amenable to deterministic structural and semantic-property oracles, especially
when each fixture supplies explicit premises, subjects, owners, and illegal states. No current run
supports them.

## Missed opportunities

`IF-03` plus `IF-04` is the best first discriminator: transform a component blacklist into one
positive boundary property with owner-real proof. `IF-07` should follow to show that polished
invariants cannot substitute for missing intent. Counting the words “valid state,” “boundary,” or
“invariant” would reward imitation and is not admissible.
