# Historical Record: Dialectical Skills Incubation

Status: superseded as a governing workpad on 2026-09-03. This file preserves only the historical
result and navigational lineage of the original two-skill project. It is not current authority for
package behavior, evaluation design, or the comparative audit.

## Governing topology

- [PHILOSOPHY.md](PHILOSOPHY.md) governs human ownership, oracle discipline, reflexive delivery,
  verification, conformance, and the evidence boundary.
- Each [`skills/*/SPEC.md`](skills/) governs its focused skill boundary, authority allocation,
  handoffs, and source negotiation. Each runtime skill's `EVAL.md` owns its obligation-to-scenario
  map, evidence assessment, and missed opportunities without becoming behavioral authority.
- [evals/promptfoo/SPEC.md](evals/promptfoo/SPEC.md) governs shared condition identity, isolation,
  oracle calibration, and pass law.
- [SDLC.md](SDLC.md) is the active comparative-audit continuity workpad. It records changing
  evidence, open premises, and the next discriminator without amending the governing documents.
- [RESEARCH.md](RESEARCH.md) and [DERIVADEX-MIGRATION.md](DERIVADEX-MIGRATION.md) retain research and
  source-repository cutover evidence; they are not runtime authority.

Explicit user direction outranks all repository artifacts within its scope. Implementation, tests,
history, and generated reports are evidence of present state, never intended-behavior authority.

## Historical result retained

The original project developed `dialectical-inquiry` and `dialectical-tutor`, their subject workpad
contract, Voice branches, a calibrated Promptfoo suite, a ceremony-matched placebo, sealed
holdouts, persistent conversations, and six runnable domain sandboxes. The cache-disabled final run
on 2026-08-23 reported 116/116 passing rows and 64/64 observed routing checks. Those fixtures and
raw results are recoverable only from Git history; they were removed after the burden-of-proof audit
found that they did not isolate useful skill effects.

That result establishes only conformance to the then-frozen automated contract on those fixtures.
It does not establish human learning, productivity, retention, Voice behavior, universal transfer,
safer delivery, or commercial value. The current comparative audit may invalidate any target,
scenario, oracle, or runtime clause on which the historical result depended.

active workpad with a precise link to its evidence.
