# Practice Drills

Open when the human needs a bounded retry, contrast case, transfer exercise, or explicit deliberate practice.

## Recruited retry

Build the smallest exercise that makes the missing function observable:

1. Preserve the live oracle answer and question.
2. Ask for one human-authored move.
3. Avoid supplying the target wording before the attempt.
4. On a partial attempt, hint at the missing relation rather than giving the question.
5. Stop after one retry plus one hinted retry.

Useful drill forms:

| Missing function | Drill |
| --- | --- |
| Causal depth | Ban the borrowed label for one explanation; require cause and effect. |
| Epistemic hygiene | Sort three claim-sized statements into evidence, inference, and unknown. |
| Falsifiability | Name one observation under which the claim must change. |
| Transfer | Change one condition and predict what should remain invariant. |
| Oracle supervision | Locate the unsupported bridge between a cited fact and the oracle's conclusion. |
| Aporic discipline | Complete: “I cannot conclude X until Y because …” |

## Deliberate practice mode

1. Ask the user to choose or provide a subject proposition.
2. Give one concise oracle answer with one realistic planted weakness.
3. Ask for one midwife move.
4. Give behavior-level feedback on one calibration dimension.
5. Repeat with less support for at most three rounds unless the user requests more.
6. End with one changed-case transfer.
7. Disclose the planted weakness and summarize demonstrated moves plus one next practice need.

Vary weaknesses across unsupported premise, evidence/inference leap, hidden applicability condition, contradiction, unfalsifiable claim, and overconfident uncertainty. Do not teach the user to assume every oracle answer is deceptive.
