# Calibration Cues

Open when judging a retry or deciding whether coaching should continue.

Evaluate the move's epistemic function, not eloquence or factual correctness.

## Classify the retry

| Result | Evidence | Response |
| --- | --- | --- |
| Adequate | Performs the missing function, even awkwardly or with a wrong subject answer. | Name the recovered function in one sentence and return to the oracle. |
| Partly adequate | Moves toward the function but leaves the decisive relation implicit. | Give one hint about that relation and allow one final retry. |
| Inadequate | Repeats the same move or delegates it back to the tutor. | After the second attempt, name the missing prerequisite and return to the oracle. |
| Misrouted | Original move was already effective or evidence is insufficient. | Return `NO INTERVENTION`. |

Adequate evidence includes one of:

- a causal relation replaces a label;
- a premise becomes visible and answerable;
- evidence and inference become distinct;
- a falsifiable prediction or defeater appears;
- an unsupported oracle step is challenged;
- a changed case is derived from the model;
- a precise unknown replaces premature certainty.

Do not claim the user “understands” from one move. Say what the move accomplished.

## Bound cargo-cult judgments

Require a visible missing relation between:

- pattern and problem mechanism;
- practice and authority or applicability;
- rule and protected invariant;
- phrase and prediction or transfer.

Jargon, error, brevity, confidence, or novice status alone are not evidence.
